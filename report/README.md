# ML4SE26 G17 — Report sources & provenance (handoff)

This folder (`report/` on the **`report` branch**) is the report deliverable.
It is self-contained: `main.tex` + `main.bib` + `figures/` + `tables/` compile to
`main.pdf`. This README documents **where every number, table, and figure comes
from**, and **which branch holds what**, so anyone can find or reproduce them.

---

## 1. Where things live (branches)

| Branch | Holds |
|---|---|
| **`report`** | The report: `report/main.tex`, compiled `report/main.pdf`, `report/figures/`, `report/tables/`, `report/scripts/`, this README. **This is the final report.** |
| **`colab-results`** | The raw per-instance model outputs (the ground-truth data): `results/{model}_{dataset}/{C1_no_retrieve,C2_always_retrieve,C3_card}.jsonl` — 12 cells (3 models × 4 datasets), leak-free. |
| **`main`** | The pipeline code (`src/`, `scripts/`), the retrieval leak fix, and the `c2refresh` notebooks used to regenerate C2. |

Final compiled report: **`report/main.pdf` on the `report` branch.**
Overleaf upload bundle: `ML4SE26_G17__report.zip` (rebuilt from this folder).

## 2. The data → results → report chain

```
[raw model outputs]            [sweep]                  [tables/figures]        [report]
colab-results:results/*  ──►  scripts/13_sweep_eval.py ──►  gen_tables.py   ──►  main.tex
(C1/C2/C3 .jsonl)              → data/_resweep/*/sweep.csv   make_figs.py
                                                              mcnemar_check.py
                                                              bootstrap_es.py
```

- **Raw outputs** (committed, `colab-results`): one JSONL line per instance with
  the prediction, ground truth, CARD score `s_hat_0`, latency, and metrics.
- **`data/_resweep/{model}_{dataset}/`** (local working copy, **not committed** —
  regenerable): the pulled C1/C2/C3 `.jsonl` plus `sweep.csv`. Produced by
  `scripts/13_sweep_eval.py` (which applies the per-dataset truncation and runs
  pyflakes). Recreate it from `colab-results` — see §5.

### Significance numbers
- **McNemar** (Table III stars, Threats §): `scripts/mcnemar_check.py` →
  `scripts/mcnemar_results.csv`. Recomputes per-instance invented-identifier flags
  with pyflakes from the raw predictions; tests CARD (C3) vs cascade (C4) at
  `T_RAG=0.05`. Stars: `***` p<0.001, `*` p<0.05.
- **Paired bootstrap** (Table II note, Threats §): `scripts/bootstrap_es.py` →
  `scripts/bootstrap_es_results.csv`. 10k-resample 95% CIs on edit-similarity
  differences (RQ1: C2−C1; RQ4: C4−C3). CPU only, no model re-run.

## 5. Reproduce end to end

```bash
# 0. deps: jsonlines rank-bm25 numpy python-Levenshtein scipy pyflakes matplotlib
#    tqdm lightgbm click tree-sitter tree-sitter-python tectonic
# 1. pull raw outputs into the local working copy (per cell, from colab-results)
git show origin/colab-results:results/<model>_<dataset>/C2_always_retrieve.jsonl \
    > data/_resweep/<model>_<dataset>/C2_always_retrieve.jsonl     # (also C1, C3)
# 2. sweep every cell  ->  sweep.csv
PYTHONPATH=src python scripts/13_sweep_eval.py \
    --results-dir data/_resweep/<cell> --dataset <dataset> \
    --out-csv data/_resweep/<cell>/sweep.csv
# 3. tables + figures + significance
python report/scripts/gen_tables.py
PYTHONPATH=src python report/scripts/make_figs.py
PYTHONPATH=src python report/scripts/mcnemar_check.py
PYTHONPATH=src python report/scripts/bootstrap_es.py
# 4. compile
tectonic report/main.tex     # or: pdflatex -> bibtex -> pdflatex x2
```
Note: `gen_tables.py`/`make_figs.py` write to `/tmp/report_work/` by default
(see the `OUT`/`RES` paths at the top of each script); copy the outputs into
`report/tables/` and `report/figures/`, which is what the committed copies are.

`bootstrap_es.py`'s RQ4 section needs the raw RepoEval benchmark files on disk
(`data/repoeval/...`, download per the loader message); the other 11 cells and all
of RQ1 run from the committed data alone.

## 6. Key facts a reader/colleague should know

- **Leakage fix (important):** an earlier harness let BM25 index the completion's
  own file, leaking the ground truth into the retrieved context (92–100% of
  instances). The fix (`exclude_file`, on `main`) was applied and **all
  retrieval-augmented results were regenerated** leak-free; every number in the PDF
  is from the corrected corpus. See the Threats section.
- All numbers in the report were cross-checked: table values == `sweep.csv` ==
  re-derivation from the raw outputs; McNemar reproduced by two independent code
  paths.
- References in `main.bib` are verified against arXiv / the PDFs in `papers/`.
