# Paper skeleton

Two-column LaTeX skeleton for the project's research paper. Section
structure follows IMPLEMENTATION_GUIDE.md §16 Phase 8.

## Build

```bash
cd paper
latexmk -pdf main.tex
```

## Filling in the `TODO`s

Sections marked `\todo{...}` need numbers/text from the Phase 6/7 runs.
Generate them with:

```bash
# Phase 6: run the full matrix (mlx-lm locally or vLLM on GPU node)
python scripts/run_full_matrix.py \
    --backend mlx --model Qwen/Qwen2.5-Coder-0.5B \
    --estimator-path models/estimator_qwen25_05b.lgb \
    --datasets crosscodeeval_py,repoeval_line,repoeval_api

# Phase 7: produce the headline numbers + plot
python scripts/06_analysis.py \
    --c1 results/crosscodeeval_py/C1_no_retrieve.jsonl \
    --c2 results/crosscodeeval_py/C2_always_retrieve.jsonl \
    --c3 results/crosscodeeval_py/C3_card.jsonl \
    --c4 results/crosscodeeval_py/C4_cascade.jsonl \
    --output-dir analysis/cce

# The PNG sweep plot goes into paper/figures/t_rag_sweep.pdf
cp analysis/cce/t_rag_sweep.png paper/figures/t_rag_sweep.pdf
```

The `analysis/cce/summary.json` contains every number referenced by a
`\todo{}` placeholder in `main.tex`. Replace each TODO with the
corresponding value from that JSON.

## Files

- `main.tex` — paper body, two-column, ~10 pages when filled in.
- `refs.bib` — references for CARD, RepoCoder, CrossCodeEval, Repoformer,
  FLARE, The Stack.
- `figures/` — destination for the T_RAG sweep plot generated by Phase 7.
